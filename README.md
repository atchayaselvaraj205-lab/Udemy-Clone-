# Udemy Clone Website

## Project Overview

The Udemy Clone Website is a frontend web development project inspired by the original Udemy learning platform. This project was created to practice and improve my HTML and CSS skills by recreating a modern educational website interface.

The website focuses on building clean layouts, responsive sections, proper content alignment, and attractive user interface design using core frontend technologies.

This project helped me gain hands-on experience in webpage structuring, styling, positioning, spacing, image handling, and responsive design concepts.

---

## Features

- Responsive navigation bar
- Hero/banner section
- Course categories section
- Featured courses display
- Popular topics section
- Footer section
- Clean and modern user interface
- Mobile-friendly layout
- Flexbox-based alignment
- Organized content sections
- Image integration
- Hover effects and styling improvements

---

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Web Design
